# Sigma People

Кабинет команды для демо после собеседования: сотрудники, отделы и отпуска.
Vue 3, TypeScript, Pinia, CASL. Бэкенд заменён mock-файлами MSW.

## Запуск

Нужен Node.js 22.12+.

```sh
yarn install
yarn dev
```

Адрес: http://127.0.0.1:5173.

Yarn 4 включён в проект. Если команды `yarn` нет, используйте
`node .yarn/releases/yarn-4.18.1.cjs install` и
`node .yarn/releases/yarn-4.18.1.cjs dev`.

| Аккаунт      | Email            | Доступ                                          |
| ------------ | ---------------- | ----------------------------------------------- |
| Руководитель | manager@demo.ru  | Редактирование, зарплаты и заявки своего отдела |
| Сотрудник    | employee@demo.ru | Своя зарплата и свои заявки                     |

Пароль: `demo1234`. Сотрудник видит только свой отдел и его сотрудников.
Страница отделов и фильтр по отделу доступны руководителю.
Руководитель может читать все отделы; редактирование доступно в своём.
Собственную заявку согласовать нельзя.

## Сценарии

- Каталог: поиск, отдел, статус, сортировка и пагинация. Параметры сохраняются
  в URL, смена фильтра возвращает на первую страницу.
- Нажатие на заголовок колонки сортирует список целиком; повторное меняет направление.
- В моках 40 сотрудников. На странице 16, 32 или 50 строк; таблица прокручивается
  внутри контейнера, заголовки колонок закреплены. Пагинация видна без прокрутки страницы.
- На небольших и низких экранах фильтры раскрываются по кнопке. Строки и фильтры
  прокручиваются в общей области, пагинация остаётся на месте.
- Поиск с задержкой 250 мс. Новый запрос отменяет предыдущий через
  `AbortController`; запоздавшие ответы игнорируются. Есть явная отмена загрузки.
- В карточке руководителя показаны заместитель и команда.
- Имя и аватар в хедере открывают карточку текущего сотрудника.
- Руководитель меняет имя, должность и статус сотрудников своего отдела.
  Список и карточка используют общие записи в Pinia.
- В разделе `/vacations` сотрудник запрашивает отпуск, руководитель согласует
  чужие заявки своего отдела. Период: 1–28 дней; пересечения запрещены.
- Заявки сортируются нажатием на заголовок колонки. Порядок хранится в Pinia,
  сортировка выполняется до пагинации; смена порядка возвращает на первую страницу.
- RU/EN, часовой пояс, светлая и тёмная темы. Настройки сохраняются.
  Для времени доступны Moscow и Amsterdam.
- `/ui-kit`: витрина компонентов и их состояний.

## Структура

```text
apps/web/src/
  app/       запуск, маршруты, макет, mock-данные и обработчики
  pages/     заголовки и композиция страниц
  widgets/   каталог, карточка, отделы, список отпусков
  features/  вход, редактирование, запрос и согласование отпуска
  entities/  session, employee, department, vacation
  shared/    HTTP-клиент, даты, настройки, пути, общие элементы
packages/
  domain/    типы, правила отпуска и политики CASL
  ui-kit/    Vue-компоненты, SCSS и токены тем
```

FSD задаёт слои и public API слайсов. Запросы лежат в `entities/*/api`,
сценарии действий — в `features/*/model`, загрузка виджетов — в их `model`.
Страницы собирают готовые элементы.

Внутренние правила домена не зависят от Vue и HTTP. Это сохраняет направление
зависимостей луковичного подхода без дополнительного архитектурного каркаса.

Pinia хранит сессию, отделы, `employees.byId` и фильтры списков.
Фильтры сохраняются при переходах между страницами, каталог синхронизирует их с URL.
Форма и состояние загрузки локальны. При смене аккаунта записи и фильтры очищаются.

Примеры TypeScript: `Page<T>`, `TableColumn<T>`, generic-компоненты таблицы
и селекта, разные типы ID, union сотрудника и руководителя. Пути и роли — enum.

UI-kit подключён через Yarn workspaces. Vue указан в `peerDependencies`
и исключён из библиотечной сборки. Приложение импортирует исходники для HMR.
Стили — SCSS с БЭМ, темы — CSS-переменные в `packages/ui-kit/src/styles/_tokens.scss`.

`UiTable<T>` собирает таблицу, состояния загрузки и ошибки, фильтры и пагинацию.
Компоненты таблицы, их типы и стили лежат в `packages/ui-kit/src/table/`.
Приложение передаёт `filterFields`, `filterValues`, `total` и модели `page` / `pageSize`.
Изменения приходят через `filter-change`, `filter-reset` и события моделей.
Без описания фильтров панель скрыта, без `total` пагинация скрыта.
Слоты `cell-*` и `actions` задают содержимое строк; `filters`, `filter-summary`, `toolbar`,
`feedback`, `error` и `pagination` позволяют заменить общие части.
Компоненты приложения описывают колонки и действия конкретного списка.

Сортировка задаётся в конфиге колонки через `sort`: `true` использует её ключ,
строка задаёт свой ключ для API, функция задаёт собственное сравнение строк.
`v-model:sort` содержит `{ key, direction }`. Каталог и отпуска передают сортировку API:
моки сортируют все результаты до пагинации. Для локальных данных есть `sortTableRows`:
сначала сортируется весь отфильтрованный массив, затем выбирается страница.
В витрине UI-kit есть пример с собственной сортировкой статусов.

Поля форм проверяются через Vuelidate: после ухода из поля и при отправке.
Сообщение находится под полем; ошибки API показываются отдельно.

`UiSelect<T>` поддерживает подпись, placeholder, ошибку и недоступные варианты.
Placeholder виден только в закрытом поле. Список вариантов оформлен в цветах темы;
есть управление стрелками, Enter и Escape. `name` добавляет скрытое поле для формы.
`UiDatePicker` использует общий попап и собственный календарь. Модель `number | null`:
timestamp в миллисекундах либо пустое значение. `min` и `max` тоже принимают timestamp.
Подпись и ошибка работают как у `UiInput`; очистка поля возвращает `null`.
Календарь поддерживает RU/EN, переход между месяцами, «Сегодня» и очистку.
Стрелки перемещают фокус по дням, Page Up / Page Down — по месяцам.
Состояния компонентов можно посмотреть на `/ui-kit`.

Стили UI-kit разделены по компонентам в `packages/ui-kit/src/styles/`.
Стили приложения лежат в `apps/web/src/app/styles/`; `index.scss` собирает их через `@use`.

## Моки и даты

`app/mocks/data.ts` содержит фикстуры, `handlers/` — обработчики по сущностям.
Сотрудники хранятся в `employeesById`, аккаунты — в `accountsByEmail`.
UUID фикстур зафиксированы в `ids.ts`, поэтому ссылки работают после обновления.
Новые заявки получают UUID через `crypto.randomUUID()`.
Общие задержка, ошибки и пагинация находятся в `helpers.ts`.
Используется настоящий `fetch`, задержка 450 мс и стандартные HTTP-коды.

Моки включены и в сборке. Изменения сбрасываются при обновлении страницы,
аккаунт запоминается на вкладке. Проверки CASL есть в маршрутах, действиях,
интерфейсе и моках. Фикстуры доступны в браузере; для настоящего приложения
права доступа проверяются сервером.

Все даты — Unix timestamp в миллисекундах. Моменты времени отображаются
через dayjs с выбранным поясом. Дни отпуска — полночь UTC:
`UiDatePicker` выбирает день в календаре и возвращает timestamp; отображение сохраняет календарный день.

## Проверка

```sh
yarn check
yarn format:check
yarn preview
```

`check` запускает ESLint, проверку FSD-импортов, TypeScript и сборку.
FSD проверяет `scripts/check-architecture.mjs` через AST TypeScript:
направление зависимостей между слоями, изоляцию слайсов и импорт через public API.
Это собственный скрипт, отдельный FSD-линтер не установлен.
Отдельно его можно запустить через `yarn fsd:check`.
Автотестов нет. `format` форматирует проект, включая вложенность Vue-шаблонов.

Сравнение версий прямых зависимостей с npm находится в [DEPENDENCIES.md](DEPENDENCIES.md).
